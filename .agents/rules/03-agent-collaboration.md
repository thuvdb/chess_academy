# Agent Collaboration Rule

Khi task liên quan nhiều domain:
1. Architect xác định boundary/contract nếu thay đổi kiến trúc.
2. Specialist implementation.
3. QA kiểm thử.
4. Security review nếu liên quan auth, dữ liệu nhạy cảm, upload, payment hoặc API exposure.
5. Architect/Orchestrator tổng hợp và xác nhận.

Không cho nhiều agent cùng sửa cùng một file/branch nếu không cần thiết.
